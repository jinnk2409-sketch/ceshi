# 投教合规助手 Demo

## 运行
用浏览器打开 `toujiao_app_demo.html`。纯前端 Mock，数据存 localStorage；宽屏显示“移动 APP + 运营后台”，窄屏只保留移动 APP。

## UI 方向
苹果式简约清爽：白底、黑灰文字、蓝色动作；绿/橙/红只表达状态。答案正文优先，来源、版本、置信度、风险提示默认折叠在“查看来源与风险”。

## 核心链路
- 知识库：种子知识已上线；新增知识默认“待审核”，点“合规上线”后才可被检索。
- 检索：中文 bigram + 同义词归一 + 核心意图加权；低于阈值不硬答。
- 合规：命中荐股、预测、收益承诺、代客决策等红线时安全拒答。
- 闭环：未答聚类、告警队列、版本动作时间线。

## 合规边界
不荐股、不预测、不承诺收益、不代客决策；不构成个性化投资建议；无来源不输出关键事实。

## 已知边界
未接真实 LLM/向量库/账号/工单；检索与合规审查为前端模拟；未做监管辖区差异、灰度发布、回归自动化。
